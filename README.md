# Sts2IOSLauncher

Experimental iPadOS port of [Sts2MobileLauncher](https://github.com/kollier-p/Sts2MobileLauncher). Target device: iPad Pro 11-inch (A1980), iPadOS 17.6.1, with user-reported jailbreak and working JIT.

Stage 1 focuses on Steam authentication, authorized depot downloads, payload processing and installation. This is development source, not a working IPA. Godot/Mono integration, complete UI parity and actual process relaunch are pending. No game assets or Steam credentials are included.
